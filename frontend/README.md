# AI Interview Practice Frontend

React + TypeScript frontend for the AI Interview Practice App.

## Run

Start the FastAPI backend first at `http://127.0.0.1:8000`.

Then run:

```powershell
npm install
npm run dev
```

Open:

```text
http://localhost:5173
```

## Build

```powershell
npm run build
```

## Lint

```powershell
npm run lint
```
